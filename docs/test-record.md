# 实测记录

## 本仓库目前的核验范围

- 已核对开发者原帖，以及 FRP、Tinyproxy、OpenSSH、libcurl、Docker 的官方资料。
- 两份 FRP 示例通过 Python `tomllib` 解析；核对了 UDP 类型与 10998/10999 端口一致性。
- Compose 示例通过 YAML 解析；本地没有 Docker CLI，未运行 `docker compose config` 或构建代理镜像。这与 Compose 实际语义、容器运行验收不同。
- 两个 shell 脚本通过 `bash -n` / `sh -n` 语法检查。
- 启动包装脚本通过模拟 curl 检查：环境变量、包含空格的参数传递、启动命令退出码、代理失败时不启动游戏、缺少命令时报错。
- Markdown 代码块成对闭合，本地文件链接目标均存在。
- 未连接真实 VPS 或真实 DST 服务端，没有实测大厅公布地址、游戏延迟、世界切换或重启恢复。
